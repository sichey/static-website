# static-website

A personal developer portfolio site, built with plain HTML, CSS, and JavaScript, and published with GitHub Pages.

🔗 **Live site:** https://sichey.github.io/static-website/

## About

This site showcases a few of my projects and includes some small interactive features. It was built as a hands-on exercise in structuring a page with HTML, styling it with CSS, and adding behavior with JavaScript — then shipping it live.

## Features

- Responsive layout that works on desktop and mobile
- Dark / light theme toggle (remembers your choice)
- Live clock that updates every second
- Countdown timer to New Year's Day
- A button that shows a random coding tip
- Project cards linking out to my other repositories

## Projects featured

- [File Organizer](https://github.com/sichey/File-Organizer)
- [Journal · Wailing Well](https://github.com/sichey/Journal-Wailing-Well)
- [BlockBustah (Video Rental)](https://github.com/sichey/Video-Rental--BlockBustah-)
- [Mood Tracker](https://github.com/sichey/Mood-Tracker)

## Built with

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)

## Running it locally

No build step needed — just clone the repo and open `index.html` in a browser.

```bash
git clone https://github.com/sichey/static-website.git
cd static-website
open index.html
```
